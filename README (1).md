# こうのす花火大会 60秒解禁テスト版

本番v28をベースに、乾杯演出の16:00ロックだけを「ページを開いて60秒後に解禁」へ差し替えたテスト専用版です。

## 確認手順
1. ページを開く
2. 乾杯ボタンを押す → 秘密POPが出る
3. `00:00:59` 前後から1秒ずつ減る
4. `00:00:00` になる
5. ロックが自動解除される
6. POPが開いたままなら自動で閉じる
7. 乾杯ボタンを押して演出が起動する
8. 全チェック済みの状態でも、60秒前は演出に進まず、60秒後は進める

本番は v28 の index.html を使用してください。
